# Maintenance Request Management System

## Overview

The Maintenance Request Management System is an application designed to help users report, manage, and track day-to-day maintenance issues and service requests. It allows users to submit maintenance requests, save written requests for future reference, and view all requests recorded during the current session.

The system helps maintain an organised record of reported issues, making it easier to keep track of previous requests and monitor maintenance-related activities.

## Features

- **Submit Maintenance Requests:** Allows users to create and submit requests for day-to-day maintenance issues.
- **Request History:** Saves user-submitted requests, providing a record of previously reported issues.
- **Session Request Tracking:** Displays all requests submitted during the current session.
- **Request Management:** Helps users organise and keep track of maintenance-related concerns.
- **Record Keeping:** Maintains a history of written requests for easier reference.

## Purpose

The purpose of this project is to simplify the process of reporting and tracking maintenance issues while providing a convenient way to retain and review previous requests.
